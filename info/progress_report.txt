CAMPUS MART - PROGRESS REPORT

=========================================

PROJECT STATUS:
CampusMart is a comprehensive student marketplace platform. The core marketplace,
authentication, real-time messaging, custom offers, checkout, online payment gateway (Razorpay/UPI),
Escrow fund protection, automated refunds, direct order cancellation, 7-day purchase returns,
inventory restocking, order & delivery confirmation, rating flows, push notifications,

=========================================
MODULE BREAKDOWN
=========================================

1. AUTHENTICATION SYSTEM [COMPLETED - 95%]
   - Registration and login with JWT authentication.
   - Email/OTP-related authentication flows are present.
   - Forgot-password and password-change screens are available.
   - Backend enforces approved college email addresses and password strength rules.
   - OTPs expire after 10 minutes, have a resend cooldown, are limited to five attempts, and are single-use.
   - JWT authentication requires the configured JWT_SECRET without an insecure fallback.
   - Password reset now uses a verified college email, one-time OTP, expiry/cooldown/attempt rules, and a new strong password.
   - Password validation is unified via a shared utility (passwordValidation.js) used by both Register and ChangePassword screens.
   - Password rules updated to minimum 8 characters including at least one letter, one number, and one special character.
   - Register and Login page email placeholders cleaned up (domain hint removed from visible UI, domain restriction retained in backend).
   - Account lockout, general request rate limiting, OAuth, biometric login, and refresh tokens remain to be added or verified.

2. STUDENT DASHBOARD [COMPLETED - 100%]
   - Bottom navigation for Home, Buy, Sell, Messages, and Profile.
   - Cart, wishlist, notification, and unread-message badges.
   - Separate admin navigation is available.

3. HOME PAGE [COMPLETED - 95%]
   - Marketplace listing feed with images, categories, search, and listing-type filters.
   - Categories include Books, Electronics, Furniture, Stationery, Clothing, and Others.
   - Item cards show seller information, price, condition, quantity, and average rating.
   - Product details show images, description, seller information, and rating summary.
   - Cleaned up availability display on product detail pages (removed extraneous '+' signs).
   - Rental cards show hourly, daily, or monthly rates and currently-rented availability.
   - RatingStars component renders fractional half-star displays accurately (e.g. 3.5 shows ★★★½☆).
   - Featured/trending sections, price filters, sorting, location filters, and announcements are not fully implemented.

4. BUY PAGE AND CHECKOUT [COMPLETED - 98%]
   - Cart and wishlist management.
   - Checkout with order summary, payment selection (Cash on Delivery, UPI, Razorpay), and delivery discussion.
   - Buyer Purchases and seller Sales tabs with status filters (All, Active, Completed, Returned, Cancelled).
   - Order Details Modal: Tapping an order card opens a detailed modal with delivery/receipt actions, invoice generation, and detailed timestamps.
   - Actions Layout: Streamlined into a unified 3-button row layout:
     * For Pending Orders: [ Cancel ] [ Call ] [ Message ]
     * For Return-Eligible Orders: [ Return ] [ Call ] [ Message ]
   - Direct Order Cancellation: Buyers can directly cancel any pending order at any time before delivery without waiting for seller approval.
   - Automated "Refund to Source": Cancelling a paid online order triggers an instant refund via Razorpay back to the buyer's original payment method.
   - 7-Day Purchase Return Window: Buyers can request a return on completed items within 7 days.
   - Automatic Inventory Restocking: Whenever an order is cancelled or marked returned, item stock is automatically incremented and reactivated.
   - Clear refund status indicators and "Refunded" badges on order cards and details modal.
   - Ecommerce-style order confirmation screen with buyer, seller, item, payment, delivery, and total details.
   - Invoice generation/printing is implemented without app action buttons in the printed output.
   - Rental checkout supports duration selection (hours/days/months) and calculates totals accurately.

5. SELL PAGE [COMPLETED - 98%]
   - Create listings with item details, category, price, condition, quantity, listing type, and images.
   - Category selection mandates input and maps original categories during edits.
   - Active listing management and sold/inactive item handling.
   - Sold Item Protection: Sold items (quantity <= 0 or marked sold) have their "Edit" button deactivated in the UI and blocked in the backend API to prevent invalid edits.
   - Sales history with buyer information and payout status tracking.
   - Return Approval: Sellers receive return requests and can approve them upon receiving the returned item, automatically triggering the buyer refund and restocking inventory.
   - Rental listings support per-hour, per-day, and per-month pricing with availability and return deadlines.

6. PROFILE PAGE & SELLER PAYOUTS [COMPLETED - 95%]

7. MESSAGING SYSTEM [COMPLETED - 100%]

9. PAYMENT SYSTEM [COMPLETED - 95%]
   - Online Payment Gateway:
     * Full integration with Razorpay Standard Checkout & UPI payments.
     * Webhook handling and UTR-based payment verification.
     * Safe inventory reservation during checkout to prevent overselling.
   - Platform Escrow Protection:
     * Buyer payments are safely held in escrow until delivery is confirmed by the buyer.
     * Seller settlements are tracked with status (not_configured, held, processing, transferred, cancelled).
   - Automated "Refund to Source":
     * Instant refunds initiated via Razorpay API back to buyer's original payment method upon order cancellation or return confirmation.

=========================================
ACTUAL TECHNOLOGY STACK
=========================================
- Frontend: React Native with Expo SDK 57 and React Native Web.
- Backend: Next.js API routes running on Node.js (webpack mode).
- Database: MongoDB with Mongoose models.
- Authentication: JWT-based authentication with AsyncStorage token persistence.
- Payment Gateway: Razorpay API & Webhooks with UPI Intent & Escrow lifecycle.
- Real-time messaging & alerts: Pusher.
- Document & Image storage: Cloudinary (images and raw PDF storage).
- Push Notifications: Firebase Admin SDK with FCM push notifications.
- Document Viewer: Shared utility (src/utils/attachmentHelper.js) using Expo FileSystem, IntentLauncher, and Sharing.
- PDF/invoice output: Expo Print and Expo Sharing on mobile; browser print on web.
- Password validation: Shared utility (src/utils/passwordValidation.js).
