1. AUTHENTICATION & SECURITY (CURRENT: 100% - COMPLETED)
================================================================================
[Current Features]:
- JWT authentication with secure secret handling.
- OTP email verification for registration and password reset (10 min expiry, 5 attempt limit).
- Unified 8+ char password validator with letter, number, and special symbol rules.
- Approved college email domain validation.
- [COMPLETED] Brute-Force Rate Limiting & Account Lockout:
  * IP-based rate limiting (10 failed attempts / 15 mins) using MongoDB TTL indexed LoginAttempt collection.
  * Account lockout on 5 consecutive failed login attempts with 15-minute lock.
  * Attempt counter alert message and automated security alert email sent to student upon lockout.
- [COMPLETED] Refresh Token Rotation (Silent Re-authentication):
  * Short-lived 15-minute Access Token + 30-day rotating Refresh Token with HTTP-only cookies on Web and secure AsyncStorage on Mobile.
  * Axios response interceptor in client.js automatically catches 401s, calls /api/auth/refresh, stores rotated tokens, and replays requests seamlessly.
  * Dedicated /api/auth/refresh and /api/auth/logout endpoints with token version invalidation.

7. DELIVERY CONFIRMATION & RENTAL LIFECYCLE (CURRENT: 100% - COMPLETED)
================================================================================
[Current Features]:
- Handshake Delivery Verification:
  * Seller marks item as "Delivered" upon handover.
  * Buyer verifies item and marks "Confirm Receipt" (or "Start Rental" for rental items).
  * Direct two-party verification ensures authentic in-person confirmation without friction.
  * Instant automatic escrow payout disbursement triggered to seller once buyer confirms receipt.
- Rental Extension Requests with Razorpay:
  * Stepper dynamically adjusts in unit increments based on the item's listing period (e.g. +1 Hour, +2 Hours for hourly rentals; +1 Day, +2 Days for daily rentals; +1 Month for monthly rentals).
  * Prorated pricing calculation based on unit rental rate (₹price * duration).
  * Integrated with Razorpay Checkout payment gateway: buyer securely pays extension fee online before rental is extended.
  * Real-time update of `rental_due_at`, `rental_duration`, and `total_price` with recorded extension history.
  * Instant automated push notification sent to seller informing them of the extension and payment confirmation.
- [COMPLETED] Dynamic Rental Overdue Countdown Timer Correction:
  * Resolved the `00:00:00` (`0m 0s`) timer issue when extending expired rentals.
  * Backend (`/api/orders/extend-rental`) and frontend now dynamically detect if `rental_due_at` is already in the past, calculating the new due date from `Date.now()` rather than old past timestamps.
  * Active ticking countdown ensures buyers and sellers always see the exact remaining time accurately.

12. DATABASE, INDEXING & INFRASTRUCTURE OPTIMIZATION
================================================================================
To ensure CampusMart scales smoothly to 10,000+ active students without lag:
1. Compound MongoDB Indexes:
   - `Item`: Create compound index on `{ category: 1, is_active: 1, createdAt: -1 }` and `{ seller_id: 1, status: 1 }`.
   - `Order`: Create index on `{ buyer_id: 1, status: 1 }` and `{ seller_id: 1, status: 1 }`.
   - `Report`: Create index on `{ status: 1, createdAt: -1 }`.
   - `ReportReason`: Create unique case-insensitive index on `{ title: 1 }`.
2. Redis In-Memory Caching (Optional):
   - Cache categories and active report reasons in Redis or fast memory cache to reduce database roundtrips to under 10ms.
3. Image Compression on Upload:
   - Compress high-resolution photos client-side before Cloudinary upload using `expo-image-manipulator` to save student mobile data and speed up listing creation.
