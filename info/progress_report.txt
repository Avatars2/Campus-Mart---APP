PROJECT STATUS:
CampusMart is a comprehensive student marketplace and rental platform. The core marketplace,
authentication, real-time messaging, community buying requests board, custom offers, checkout,
online payment gateway (Razorpay/UPI), Escrow fund protection, automated refunds, direct order
cancellation, 7-day purchase returns, inventory restocking, order & delivery confirmation with
custom in-app dialogs, rating flows, push notifications, admin moderation, dynamic report reasons
management, admin notifications with PDF attachments, enhanced seller payout history,
admin daily activity analytics with date-range PDF exports, rental extensions with countdown timers,
OpenStreetMap CartoDB location sharing with live in-chat map previews, and 24-hour newly added item
labels are fully implemented, verified, and active.

1. AUTHENTICATION SYSTEM [COMPLETED - 100%]
   - Registration and login with JWT authentication.
   - Email/OTP-related authentication flows are present.
   - Forgot-password and password-change screens are available.
   - Backend enforces approved college email addresses and password strength rules.
   - OTPs expire after 10 minutes, have a resend cooldown, are limited to five attempts, and are single-use.
   - JWT authentication requires the configured JWT_SECRET without an insecure fallback.
   - Password reset now uses a verified college email, one-time OTP, expiry/cooldown/attempt rules, and a new strong password.
   - Password validation is unified via a shared utility (passwordValidation.js) used by both Register and ChangePassword screens.
   - Password rules updated to minimum 8 characters including at least one letter, one number, and one special character.
   - Register and Login page email placeholders cleaned up (domain hint removed from visible UI, domain restriction retained in backend).
   - Brute-Force Rate Limiting & Account Lockout:
     * IP-based rate limiting (maximum 10 failed attempts per 15 minutes across network) using MongoDB TTL indexed LoginAttempt collection.
     * Account lockout on 5 consecutive failed login attempts with a 15-minute cooldown.
     * Countdown indicator showing remaining login attempts before lockout.
     * Automated security alert email dispatched via Gmail SMTP upon account lockout.
   - Refresh Token Rotation & Silent Re-authentication:
     * Short-lived 15-minute Access Token + 30-day rotating Refresh Token with HTTP-only cookies on Web and secure AsyncStorage on Mobile.
     * Axios response interceptor in client.js seamlessly intercepts 401 errors, pauses requests, calls /api/auth/refresh, stores rotated tokens, and replays requests without session disruption.
     * Dedicated /api/auth/refresh and /api/auth/logout routes with token version invalidation.

=========================================
ACTUAL TECHNOLOGY STACK
=========================================
- Frontend: React Native with Expo SDK 57 and React Native Web.
- Maps & Geospatial: react-native-maps with CartoDB Voyager OpenStreetMap CDN tiles.
- Backend: Next.js API routes running on Node.js (webpack mode).
- Database: MongoDB with Mongoose models.
- Authentication: JWT-based authentication with AsyncStorage token persistence.
- Payment Gateway: Razorpay API & Webhooks with UPI Intent & Escrow lifecycle.
- Real-time messaging & community alerts: Pusher channels.
- Document & Image storage: Cloudinary (images and raw PDF storage).
- Push Notifications: Firebase Admin SDK with FCM push notifications.
- Document Viewer: Shared utility (src/utils/attachmentHelper.js) using Expo FileSystem, IntentLauncher, and Sharing.
- PDF/invoice output: Expo Print and Expo Sharing on mobile; browser print on web.
- Password validation: Shared utility (src/utils/passwordValidation.js).
